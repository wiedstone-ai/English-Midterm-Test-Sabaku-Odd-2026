🛠️ Petunjuk Update Kode Google Apps Script

Ikuti 4 langkah mudah berikut agar password dapat disimpan di Google Sheets.

ℹ️ Mengapa ini penting? Google Apps Script Web App memerlukan pembuatan Versi Baru (New Version) setiap kali kode diperbarui. Jika belum di-update, server Web App masih memakai kode lama sehingga tidak dapat mengenali perintah simpan password.

Langkah-Langkah Pembaruan:

  1. Buka Spreadsheet Google: Klik link berikut English-Midterm-Test-Sabaku-Odd-2026 ↗.
  2. Di menu atas Google Sheets, klik menu Ekstensi (Extensions) → pilih Apps Script.
  3. Di editor Apps Script, hapus seluruh kode lama pada file Kode.gs (atau Code.gs).
  4. Klik tombol hijau di bawah untuk menyalin seluruh kode baru, lalu Paste (Ctrl+V) ke editor Apps Script:
    ✅ Berhasil Disalin!
  5. Klik ikon disket 💾 (atau tekan Ctrl + S) untuk menyimpan kode.
  6. (PENTING!) Deploy Versi Baru:
    • Klik tombol biru Terapkan (Deploy) di pojok kanan atas → pilih Kelola penerapan (Manage deployments).
    • Klik ikon pensil ✏️ (Edit) pada Web App aktif.
    • Pada dropdown Versi (Version), pilih Versi baru (New version).
    • Pastikan Yang memiliki akses (Who has access) disetel ke Siapa saja (Anyone).
    • Klik tombol Terapkan (Deploy).
  7. Kembali ke halaman ini dan klik tombol "🔄 Muat Ulang dari Sheet". Status akan berubah menjadi hijau dan Anda dapat menyimpan password dengan sukses!
